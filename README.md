# Sustainable Smart City

## Project Description

The Sustainable Smart City is an innovative project that integrates renewable energy, automation, digital logic and safety systems to create a smarter and more sustainable urban environment. Our project consists of four major modules.

### 1. Solar-Powered Smart Street Lighting System
This system uses solar panels to convert sunlight into electrical energy, which is stored in a rechargeable battery and used to power streetlights. A mobile application or dedicated interface allows users to monitor energy generation, storage and consumption. This helps promote renewable energy and efficient electricity management.

### 2. Smart Parking System Using Ultrasonic Sensor
The smart parking system uses an ultrasonic sensor to detect vehicles approaching the parking area. The sensor sends distance information to the Arduino Uno, which controls the indicator lights. This demonstrates automated vehicle detection and efficient parking management.

### 3. Smart Fire Alarm and Alert System
This system is designed to detect fire-related conditions in buildings and apartments. When the fire sensor detects a fire-related condition, the Arduino Uno activates a buzzer to generate an alarm sound and switches on an LED indicator as a visual warning. This demonstrates an automated safety alert mechanism.

### 4. Automatic Traffic Light System Using NAND Gates
This module demonstrates traffic signal control using NAND gate-based digital logic. The system controls three LED indicators representing red, yellow and green signals. The logic circuit manages the signal outputs according to predefined conditions, demonstrating the practical application of digital electronics in traffic management.

## Technologies Used
- Arduino Uno
- Solar Panel
- Ultrasonic Sensor
- Fire Sensor
- NAND Gate IC
- LEDs and Buzzer
- Mobile Application Monitoring

## Project Outcome

This project demonstrates how renewable energy, sensor-based automation and digital logic can work together to improve energy efficiency, parking management, building safety and traffic control.

## Future Scope

The project can be enhanced through IoT integration, real-time mobile notifications, intelligent energy monitoring and centralized smart city management.
